## Cómo entregar en AVA

1. Abrir `Informe_Plan_Pruebas_CuidartePlus.md`.
2. Completar en la portada: apellidos, sección y docente.
3. Copiar a Word (o exportar) y aplicar formato oficial:
   - Títulos Arial 12
   - Cuerpo Arial 11
   - Interlineado 1,5
   - Texto justificado
4. Exportar PDF o dejar Word.
5. Subir a AVA el día del cuestionario.
6. Cada integrante rinde el cuestionario individual (sin IA, un intento).
